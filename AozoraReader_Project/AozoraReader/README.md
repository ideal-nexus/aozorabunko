# 青空リーダー (Aozora Reader)

青空文庫の全作品をオフラインに保存し、快適に縦書き読書できるAndroidアプリです。

## 主な機能
- **完全オフライン読書**: ダウンロード済みの作品は電波なしで閲覧可能
- **美麗な縦書き・ルビ**: HTML5/CSSによる本格的な縦書き・振り仮名表示
- **電子書籍リーダーUX**:
  - 画面左側タップ: 次ページへめくる（行ピッチ吸着スナップ）
  - 画面右側タップ: 前ページへ戻る
  - 画面中央タップ: 上部メニュー（文字サイズ変更、ダークモード切替、戻る）
- **しおり機能**: 読書進捗率（%）を自動保存・復元
- **本棚管理**: 保存済み作品の一覧表示・進捗率表示・作品削除
- **全作品検索**: 青空文庫公式カタログからタイトル・作家名を高速検索
